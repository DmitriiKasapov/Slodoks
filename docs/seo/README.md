# Карта URL старого сайта

`old-site-urls.csv` — структура действующего сайта https://slodocs.si/ на
Laravel. При переносе на WordPress эти адреса должны сохраниться символ
в символ либо получить 301-редирект.

## Как получена

Обход сайта невозможен: `robots.txt` блокирует ClaudeBot, сервер отдаёт 403.
Поэтому данные сняты из исходников проекта `D:\Projects\SloDoks`:

- статические маршруты — `routes/web.php`;
- состав `sitemap.xml` — `app/Http/Controllers/SitemapController.php`;
- страницы услуг, их заголовки и мета-теги — `pgexport/data_export.json`,
  выгрузка боевой базы от 19.07.2026.

Дата снятия: 02.08.2026.

## Колонки

| Колонка | Значение |
|---|---|
| `url` | Путь без домена |
| `type` | static / service / redirect / protected |
| `title` | Заголовок страницы |
| `seo_title`, `seo_description` | Мета-теги, если заданы в базе |
| `in_sitemap` | Входит ли в `sitemap.xml` |
| `indexable` | Должна ли страница быть в индексе |
| `source` | Откуда взята строка |
| `notes` | Примечания |

## Чего здесь НЕТ

**Это структура сайта, а не выгрузка из Google Search Console.** Файл
показывает, какие страницы сайт отдаёт, но не показывает:

- какие страницы Google реально проиндексировал;
- какие приносят трафик и по каким запросам;
- старые адреса, которых уже нет в коде, но которые остались в индексе.

Последний пункт критичен: если сайт когда-то менял структуру, в индексе могут
жить URL, о которых исходники не знают. Их найдёт только Search Console.

**Что нужно сделать дополнительно:** выгрузить в Google Search Console
Индексирование → Страницы, сохранить рядом как `gsc-export.csv` и объединить.

## Что уже видно

1. **Дубли.** `vaje-za-pravilno-izgovorjavo-glasov-s-z-c` и
   `vaje-za-pravilno-izgovorjavo-glasov-s-z-in-c` — почти одинаковые адреса
   с одинаковым заголовком. Похоже на дубль контента. Перед переносом
   выяснить, какая из страниц в индексе и приносит трафик; вторую закрыть
   301-редиректом на первую.
2. **Мета-теги заполнены только у одной услуги** из восьми. У остальных
   `seo_title` и `seo_description` пустые — WordPress будет генерировать их
   сам, и это шанс улучшить сниппеты, а не потерять их.
3. **Слаг `zacetni_sklop` выбивается из общего стиля** — подчёркивания вместо
   дефисов. Менять его нельзя: адрес в индексе. Переносим как есть.
4. **Язык контента — словенский.** Услуги описаны на словенском, не на
   русском.
