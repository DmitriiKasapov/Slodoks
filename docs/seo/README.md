# Карта URL старого сайта

`old-site-urls.csv` — адреса действующего сайта https://slodocs.si/ на
Laravel. При переносе на WordPress они должны сохраниться символ в символ
либо получить 301-редирект.

## Источники

| Файл | Что это |
|---|---|
| `old-site-urls.csv` | Сводная карта, с ней сверяемся при создании страниц |
| `gsc-export.csv` | Выгрузка Google Search Console от 02.08.2026, как есть |

Структура маршрутов дополнительно сверена с `routes/web.php` и
`SitemapController.php` в проекте `D:\Projects\SloDoks`.

Обход сайта невозможен: `robots.txt` блокирует ClaudeBot, сервер отдаёт 403.

## Что в индексе

10 страниц: 5 статических (`/`, `/catalog`, `/contact`, `/terms`,
`/privacy`) и 5 услуг.

Темы услуг: налоговое резидентство, налоговый вычет на иждивенцев при ВНЖ,
порог 183 дней, оформление ребёнка в школу, поиск врача.

Не индексируются: `/search` (301 на `/catalog`), `/services/{slug}/content`
(закрыт токеном), `/admin`, `/payment`, `/webhooks`.

## Чего не хватает

**1. Заголовки и мета-теги.** В выгрузке GSC их нет, колонки `title`,
`seo_title`, `seo_description` пустые. Нужна выгрузка из боевой базы
slodocs.si: `slug`, `title`, `seo_title`, `seo_description`, `is_active`.
Без них переносим страницы вслепую и теряем наработанную релевантность.

**2. Услуги, которых нет в индексе.** GSC показывает только
проиндексированное. Если на сайте есть страницы, до которых Google не дошёл,
они здесь не появятся — их найдёт только выгрузка базы или `sitemap.xml`.

**3. Трафик и запросы.** Отчёт «Результаты поиска» покажет, какие страницы
реально приносят посетителей. Это нужно, чтобы понимать, какие страницы
трогать осторожнее всего.

## Колонки

| Колонка | Значение |
|---|---|
| `url` | Путь без домена |
| `type` | static / service / redirect / protected |
| `title` | Заголовок страницы |
| `seo_title`, `seo_description` | Мета-теги |
| `in_sitemap` | Входит ли в `sitemap.xml` |
| `indexable` | Должна ли страница быть в индексе |
| `last_crawl` | Дата последнего сканирования Google |
| `source` | Откуда взята строка |
| `notes` | Примечания |

## Про слаги

Слаги — транслитерация русского без диакритики: `mozno-li-stat-nalogovym-
rezidentom-ranse-183-dnei`, `kak-naiti-vraca-v-slovenii-...`. Выглядят
непривычно (`vraca`, `skolu`, `ranse`), но **менять их нельзя** — они в
индексе. Переносим символ в символ.
