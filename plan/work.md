## 🔴 Критично — пока старый сайт живой

- [ ] **Снять полную карту старого сайта slodocs.si**
  - Выгрузить список проиндексированных URL из Google Search Console
    (Индексирование → Страницы) и/или обходом Screaming Frog
  - По каждому URL сохранить: Title, Meta Description, H1
  - Положить в `docs/seo/old-site-urls.csv`, закоммитить
  - Без этой выгрузки переезд делается вслепую — сделать до любых правок
    на боевом сайте

- [ ] **Зафиксировать структуру ЧПУ нового сайта по выгрузке**
  - Настройки → Постоянные ссылки привести к формату старого сайта
  - Составить таблицу соответствия «старый URL → новая страница»
  - Отметить URL, которые изменятся — под них нужны 301-редиректы
